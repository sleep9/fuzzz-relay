# Fuzzz

> The web was meant to be a conversation. The platforms turned it into a lecture — they own the room, they own the record, they decide what gets remembered. Fuzzz takes the margin back. Your notes are yours to sign, yours to keep, held by a network that no one company can silence.

This is the repository for the **Fuzzz Relay**. A Gun.js relay that forms part of the federated network powering Fuzzz.

Fuzzz content is cryptographically signed by its owner and propagated across a network of independently operated relays. The relay validates incoming writes, enforces network rules, and helps distribute signed content across the federation without taking ownership of it.

## Running a Relay

Fuzzz Relay runs in a Node.js environment.

Clone the repository:

```bash
git clone https://github.com/sleep9/fuzzz-relay.git
cd fuzzz-relay
```

Install dependencies:

```bash
npm install
```

Start the relay:

```bash
npm start
```

The relay exposes a Gun.js endpoint for clients and other relays to connect to.

## Relay Security

Fuzzz uses cryptographic signatures and proof of work to protect the network from unauthorized writes and Sybil attacks.

Incoming posts are validated by the relay before being accepted and propagated. Posts are signed by their originating user and can be independently verified by other nodes on the network.

Fuzzz also uses **Equi-X** proof of work as part of its anti-abuse mechanism.

## Federation

Fuzzz uses a federated network of independently operated Gun.js relays.

Relays authenticate with public keys before participating in the Fuzzz federation. This currently makes participation permissioned while the network and protocol continue to develop.

If you would like to operate a Fuzzz Relay on the default network, email **operations@fuzzz.cloud** with the subject **Relay Operations** and provide the public key generated by `generate-pubkey.js`.

You are not limited to the default Fuzzz federation. You can operate your own federation and configure your own clients and relays accordingly.

## Architecture

The relay is built around:

- **Gun.js** for decentralized data synchronization
- **SEA** for cryptographic signatures and identity
- **Equi-X** for proof of work
- **Node.js** for the relay server
- **Public-key authentication** for relay federation

The relay maintains the Gun graph while validating writes against the Fuzzz protocol before allowing them to propagate through the network.
